File format

UTF-8 or Shift-JIS CSV with a header row. One file can hold several boxes. Required: box, plus item_name or club_option on each row.

box,item_name,club_option,flex,qty,customer,note
  • box: cargo code + number, e.g. GN-3. The cargo must exist; new boxes are created.
  • club_option: one label, e.g. Driver 10.5, Driver head 9.5, Iron · Graphite 5, Iron Steel, Wedge 52° (the ° and · are optional). Labels come from Admin → Club options.
  • flex: L, A, R, SR, S, X or empty · qty: default 1
  • Older files still work: type, loft, brand, model, shaft_material, club_number, condition, price_jpy, quantity_unit, color, specification.
