File format

UTF-8 or Shift-JIS CSV with a header row. One file can hold several boxes. Required columns: box, type, item_name.

box,item_name,type,qty,quantity_unit,brand,model,club_type,club_number,loft,flex,shaft_material,specification,color,condition,price_jpy,customer,note
  • box: cargo code + number, e.g. GN-3. The cargo must exist; new boxes are created.
  • flex: L, A, R, SR, S, X or empty · shaft_material: steel / graphite or empty
  • condition (Japan condition): new / used (default new) · qty: default 1 · quantity_unit: pcs, set, pair, dozen, box (default pcs)
  • price_jpy is the optional amount. Headers name, amount and unit also work.
