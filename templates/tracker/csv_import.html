File format

UTF-8 or Shift-JIS CSV with a header row. One file can hold several boxes. Required: box (or cargo for a new box), plus item_name or club_option on each row.

box,cargo,kind,item_name,color,club_option,flex,qty,amount_jpy,cargo_fee_jpy,customer,note
  • box: leave it empty to get a new Box ID like OCT26-KB-3 for the company in cargo – each bag row starts a new box and the item rows below it go in it. Or give a Box ID like OCT26-KB-3; an older ID like GN-3 only works for boxes that already exist.
  • kind: bag for the box's golf bag (bag name in item_name, plus color, customer, note); empty for the items inside the bag. Each box needs exactly one bag row (or already has its bag when you add items to it); a box with no bag or two bags is rejected with its row numbers.
  • club_option: one label, e.g. Driver 10.5, Driver head 9.5, Iron · Graphite 5, Iron Steel, Wedge 52°, Wood 3W (or wood 3, 3W), Hybrid 4 (or 4H), Putter 34 (the °, · and ″ are optional). Labels come from Admin → Club options.
  • flex: L, A, R, SR, S, X or empty · qty: default 1
  • amount_jpy: price per piece in whole yen · cargo_fee_jpy: on the bag row. 12500, 12,500 and ¥12,500 all work.
  • Older files still work: type, loft, brand, model, shaft_material, club_number, condition, price_jpy, quantity_unit, color, specification.
